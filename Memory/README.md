# Memory

用户偏好和经确认的经验以纯文本保存。正文是事实来源，索引只是可删除、可重建的派生物。

## 内容边界

可以记录：经用户确认的岗位背景、沟通偏好、常用知识锚点、脱敏后的经验结论和踩坑说明。

不得默认记录：密码、Token、Cookie、客户标识、个人隐私、完整邮件/日志、未确认推断或第三方机密。无法判断时按敏感处理并先询问。

## 建议格式

```text
# 标题

- status: confirmed | draft
- sensitivity: public | internal | sensitive
- source: 用户确认 / 任务归档路径
- updated: YYYY-MM-DD

正文只记录完成当前协作所需的最小信息。
```

## 生命周期

- **写入**：向用户展示候选内容，确认后保存；
- **更新**：保留可审阅的差异，不静默改写历史结论；
- **迁移**：复制纯文本即可，索引在目标环境重建；
- **删除**：正文删除后同步清理索引和缓存；
- **同步**：敏感 Memory 默认不离开本地/内网，需另行授权。

当前目录没有 Memory 执行器、索引或真实用户档案。
