# 多分支同码

## 适用范围

将已经确认的改动同步到多个目标基线，创建隔离工作分支并提供差异供人工判断。当前仓库只提供手册，不包含仓库连接器或自动推送能力。

## 输入

- 仓库与源分支；
- 目标分支清单；
- 提交或文件范围；
- 冲突、测试和命名策略。

## 流程

1. 检查工作区、源提交和目标分支是否明确；
2. 列出每个目标分支的 Todo、风险和验证方式；
3. 生成同步 Plan 并等待确认；
4. 只在本地创建隔离工作分支、应用改动并运行测试；
5. 输出差异、冲突和未通过项，由人工决定后续提交或推送。

## 输出

每个目标基线的分支名、应用结果、差异摘要、冲突列表和真实验证证据。

## 审批点

创建本地工作分支可在已确认 Plan 内执行；commit、push、开 PR、merge、rebase 共享分支或删除分支均需动作级确认。

## 禁令

- 未经确认不得 push、merge、rebase 共享分支或删除分支；
- 冲突不得自动选择业务语义；
- 不覆盖用户未提交的工作，不用强推掩盖分支差异。

## References

目标仓库的分支映射或验证命令只能从经确认的 `References/` 文件加载；当前未配置。
