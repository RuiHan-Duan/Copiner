# 邮件场景

## 适用范围

对已授权邮箱做检索、摘要、待办提取和回复草稿。当前仓库没有邮箱连接器，不代表已接入任何账户。

## 输入

- 邮箱账号或范围的明确授权；
- 时间、发件人、主题等检索条件；
- 用户关注点、语言和输出格式；
- 附件敏感级别与允许的 Provider 边界。

## 流程

1. 确认账号、文件夹、时间范围和允许动作；
2. 先做只读检索与摘要，区分事实、推断和待办；
3. 需要回复时只生成草稿并列出收件人、主题、正文和附件；
4. 生成 Plan，发送或改变邮箱状态前逐项等待确认；
5. 完成后解释处理结果，归档仅记录经确认的必要信息。

## 输出

摘要、待办、草稿或待执行动作清单；不得把草稿描述为已发送。

## 审批点

发送、转发、删除、移动、加标签、下载附件以及触发 eHR/问题单流程都需要与具体邮件绑定的动作级确认。

## 禁令

- 未经动作级确认，不发送、转发、删除、移动邮件或改变已读状态；
- 不读取未授权邮箱，不向外部模型发送企业或个人敏感信息；
- 不猜测收件人、附件或企业流程必填字段。
