# BIOS/BMC 文档与日志

## 适用范围

BIOS/BMC 公开或已授权文档检索、脱敏日志结构化、候选归因和可复核报告。当前仓库只有手册，不包含 RAG、日志解析器或生产资料。

## 输入

- 用户明确指定的文档范围、平台/机型和版本；
- 经授权且完成敏感标注的日志；
- `References/` 中由本 Skill 明确引用的字段或格式说明。

## 流程

1. 确认资料来源、授权范围、平台和期望输出；
2. 对客户标识、序列号、地址、账号和拓扑信息脱敏；
3. 文档按章节与表格边界检索，日志先结构化再关联证据；
4. 区分事实、候选原因和待验证项；
5. 生成 Plan，涉及工具或外部资料前等待确认；
6. 以费曼方式解释结论，接受纠偏后再归档。

## 输出

带来源、版本、证据、不确定性和下一步验证建议的报告。没有证据时返回未确认，不补造根因。

## 审批点

上传资料、调用非本地 Provider、访问企业知识库或归档含敏感信息的报告前必须逐项确认。

## 禁令

- 客户标识、序列号、地址和原始敏感日志不得进入外部模型；
- 不读取未授权资料，不把公开文档与企业内部基线混为一谈；
- 不把相关性、模型推测或历史相似案例写成已确认根因。
