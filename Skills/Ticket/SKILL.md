# 问题单与企业流程

## 适用范围

对已授权的问题单、审批或 eHR 流程做只读查询、字段整理和待提交草稿。当前仓库没有企业连接器。

## 输入

- 目标系统、流程和账号授权；
- 经确认的模板、字段字典和状态定义；
- 附件、关联邮件及其敏感级别；
- 期望动作与完成标准。

## 流程

1. 确认系统、流程、模板版本和授权范围；
2. 优先使用官方 API 契约，浏览器自动化只作为经评审的兜底；
3. 校验字段、附件和关联对象，缺失内容返回用户补充；
4. 生成待提交 Plan，展示动作目标、字段和值；
5. 获得动作级确认后才允许提交，随后读取回执核对结果。

## 输出

字段草稿、验证错误、待确认动作或真实系统回执；没有回执时不得声称已提交成功。

## 审批点

提交、关闭、转派、评论、上传附件或批准电子流均需逐次确认。

## 禁令

- 未经确认，不提交、关闭、转派问题单或电子流；
- 不绕过企业鉴权，不猜测必填字段或状态语义；
- 不用页面占位或历史样例冒充当前系统数据。

## References
