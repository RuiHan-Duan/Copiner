# 开发规范

- 需求范围只认 `Docs/02-任务清单.md`，技术变更同步 `Docs/03-技术选型.md`。
- 领域规则优先放在 `CoreEngine`，UI 和 Tauri 命令只做适配。
- Provider、Tool、Skill 通过接口或注册表扩展，禁止把厂商细节写入工作流状态机。
- 未确认的 Plan 不能执行；外部副作用还需动作级确认和审计记录。
- 页面无真实数据时展示空态，不写死指标冒充结果。
- 密钥只从环境或系统密钥链读取，禁止提交 `.env`、Token、证书和生产样本。
- 模块变更同步 README；以真实 build/test/lint 输出作为完成证据。
