# 项目介绍

Copiner 采用 Monorepo，以运行时和可移植配置边界组织代码。

```text
Desktop/               桌面对话、Todo、Plan 与执行日志 UI
Crates/CoreEngine/     Provider 路由、工作流与工具注册表领域内核
Crates/DesktopHost/    Tauri 本地宿主和命令适配
WorkspaceService/      RAG、记忆、队列和企业系统网关边界
Skills/                按场景渐进加载的能力手册
References/            Skill 按需引用的重资料
Hooks/                 会话启动动态上下文
Memory/                用户可编辑、可迁移的纯文本记忆
Docs/                  需求、规范与技术决策
Plans/                 跨模块变更计划与验收记录
```

当前骨架只覆盖 M0/M1 的结构与核心状态机。真实 LLM、RAG、企业系统和浏览器自动化均未接入。
