# 技术选型

## 已确认的骨架决策

| 层 | 选型 | 原因 |
|---|---|---|
| 桌面 | Tauri 2 + Vue 3 + TypeScript | 本地优先、包体轻，Web UI 生态成熟 |
| 内核 | Rust workspace | 强类型表达状态机与权限边界，可与 Tauri 同进程复用 |
| 前端工具链 | pnpm 11 + Vite 6 | 与 SmartPort 的可复现工具链保持一致 |
| Harness | Markdown + JSON | 可 diff、可迁移、可人工编辑并支持渐进加载 |
| 云上 Workspace | 独立服务边界，协议待 M1 评审 | 避免桌面内核与部署形态耦合 |

RAG 向量库、Workspace Web 框架、模型 SDK、插件沙箱和企业系统协议仍待专项评审，不在骨架阶段引入。
