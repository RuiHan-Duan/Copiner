# 技术选型

技术选型已经落入代码、锁文件、构建入口和 CI。修改不是零成本，需按 `01-开发规范.md` 走跨界 Plan。

## 已确认决策

| 层 | 选型 | 原因 |
|---|---|---|
| Desktop | Tauri 2 + Vue 3 + TypeScript | 本地优先、包体轻，Web UI 生态成熟 |
| CoreEngine | Rust stable library | 强类型表达状态机、安全边界和可复用领域规则 |
| DesktopHost | Tauri 2 Rust binary | 与 CoreEngine 同进程复用，承接系统能力 |
| Workspace | 独立 Rust binary 边界 | 先固定部署边界，不提前绑定 Web/存储框架 |
| Harness | Markdown + JSON Schema | 可 diff、可迁移、可人工审阅和渐进加载 |
| Monorepo | Cargo workspace + 单 Desktop package | 跨边界 Plan、契约和验证可以一次完成 |

## 工具链

| 范围 | 工具与版本 | 固定位置 |
|---|---|---|
| Desktop runtime | Node `>=24 <25`（CI 24.14.0） | `package.json`、CI |
| 包管理器 | pnpm `11.12.0` | packageManager、engines、唯一 lock、CI |
| 前端构建 | Vite 6、Vue 3、TypeScript 5.6 | `Desktop/package.json` |
| Desktop 宿主调用 | `@tauri-apps/api` 2.x | 集中在 `Desktop/src/Shared/local-harness-client.ts` |
| 前端质量 | vue-tsc、ESLint 9、工程一致性脚本 | scripts、Makefile、CI |
| Rust | stable + rustfmt + clippy | `rust-toolchain.toml`、CI |
| 统一入口 | Makefile + PowerShell 7 `build.ps1` | 根目录 |
| Linux Tauri CI | Ubuntu + WebKitGTK 4.1 官方前置依赖 | `.github/workflows/ci.yml`、根 README |

Desktop 是单 package，不建立 pnpm workspace packages。`Desktop/pnpm-workspace.yaml` 只限制允许执行安装脚本的依赖。只允许 `pnpm-lock.yaml`，禁止 npm/yarn 锁文件。

## 依赖方向

```text
Desktop --Tauri command/event--> DesktopHost --> CoreEngine
WorkspaceService ---------------- 独立运行时边界
CoreEngine ----------------------- 不依赖 UI、网络、存储或厂商 SDK
```

Provider、Tool、Hook 的实现通过适配层接入。厂商错误、成本和网络细节要转换为稳定领域契约，不能渗入 Workflow。

## 已确认安全架构

- 数据敏感级别：Public / Internal / Sensitive / Unknown；
- Provider 边界：External / Enterprise / Local；
- Internal、Sensitive、Unknown 不得使用 External；
- Tool 副作用：ReadOnly / LocalMutation / ExternalMutation；
- Mutation 默认需要动作级 Approved；
- 配置文件不保存密钥，真实凭据只允许环境或系统密钥链。

当前规则是可运行安全骨架：Desktop 可推进一个不含模型/工具的内存 Workflow 会话；仍不包含真实 Provider、Tool 执行器、凭据管理或审计存储。

## 暂缓事项

以下选型需专项评审，未经确认不得引入：

- LLM SDK、模型清单、Key 池、成本和降级策略；
- RAG 向量库、切分框架和文档许可策略；
- Workspace Web 框架、数据库、消息队列和同步协议；
- 浏览器自动化方案及企业系统认证方式；
- 插件沙箱（WASM、独立进程或其他）；
- 桌宠渲染（Live2D、Spine 或序列帧）；
- 打包签名、自动更新和企业分发。
